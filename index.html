Messaging App

   

This project features a real-time messaging application built with a robust backend in Spring Boot and a sleek frontend in React. WebSockets are used to enable real-time communication between users. For data persistence, MongoDB is utilized to store and retrieve messages. Security measures are in place to ensure safe interactions, and the design is crafted to provide an intuitive and responsive user interface.

Check it out!

Weather Widget

 

For my Mobile Applications class, I developed a weather widget using the Flutter framework with Dart, following the Model-View-Controller (MVC) architecture. The widget allows users to enter a city name and retrieve real-time weather data using the OpenWeather API. It displays key weather details such as temperature, and conditions in an intuitive and responsive UI. This project showcases API integration, state management, and clean architectural design within Flutter.
